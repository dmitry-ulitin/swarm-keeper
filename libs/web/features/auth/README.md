# @swarm-keeper/feature-auth

Sign-in, invitation and password-reset screens: `/login`, `/invite/:token`, `/reset-password`, and the signed-in placeholder at `/`. Translations are in `apps/web/src/i18n/auth/{en,ru}.json` (scope `auth`) and `errors.auth.*` in the root files. Mockups: `docs/design/mockups/auth/`.
