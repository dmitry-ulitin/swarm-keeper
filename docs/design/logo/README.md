# Logo

The Swarm Keeper mark — "Swarm family": six dots around an amber center. Colors are baked into the files (no `currentColor`).

- `swarm-keeper-mark.svg` — main mark, for light backgrounds: dots #2f5d8c (`brand`), center #b87a1e (`accent`).
- `swarm-keeper-mark-dark.svg` — for dark backgrounds: dots #8db8e8, center #e2b05c.
- `swarm-keeper-mark-small.svg` — for 16–24 px: six equal, larger dots.
- `swarm-keeper-mark-mono.svg` — single color, #1f1b16 (`ink`).
- `swarm-keeper-app-icon.svg` — app icon, 1024×1024, 228 px corner radius, #2f5d8c fill.
