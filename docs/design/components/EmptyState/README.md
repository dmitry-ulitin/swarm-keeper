# EmptyState

A screen with nothing on it yet: it explains what will appear here and offers one or two actions to make it appear.

**Structure:** a small geometric illustration made of tiles (`media-placeholder`, `brand-container`, `brand`, `accent`; no people or characters) · a heading in `title` · one sentence of `body` in `ink-muted` · a primary action and, if needed, an outline one. Text width at most 360px, vertical spacing `space-8`.

**Copy by place:**

| Where | Heading | Actions |
| --- | --- | --- |
| Timeline, first visit | "Your family's photos will appear here" | Upload · Invite relatives |
| Album | "No photos in this album yet" | Upload · Pick from timeline |
| Documents | "No documents yet" | Add document |
| Search with no results | "Nothing found for “…”" | Reset filters |
| Trash | "Trash is empty" | — (a sentence explaining the retention period) |

**Don't:** jokes, exclamation marks, big illustrations that push the action off screen.
