# Workspace Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pnpm monorepo where an empty NestJS API, its worker entry point, an Angular 22 app and all planned libraries build, typecheck, test and lint, and Sheriff enforces module boundaries.

**Architecture:** Source-only library packages are resolved through `tsconfig.base.json` path aliases. The API and worker compile with `tsc` (with `rootDir` at the repo root so imported library sources are compiled into the app's `dist`), and `tsc-alias` rewrites aliases to relative paths. The worker reuses API modules via `@swarm-keeper/api` and boots with `NestFactory.createApplicationContext`. The web app is generated by the Angular CLI.

**Tech Stack:** Node 26, pnpm 12.14.0, TypeScript, NestJS (Express), Angular 22, Vitest (+ `unplugin-swc` for Nest decorator metadata, `vite-tsconfig-paths`), ESLint flat config, typescript-eslint, angular-eslint, Sheriff (`@softarc/sheriff-core`, `@softarc/eslint-plugin-sheriff`), Prettier.

**Spec:** `docs/superpowers/specs/2026-11-23-workspace-scaffold-design.md`

## Global Constraints

- Everything in English; no Russian outside future `ru` translation files.
- Package names: `@swarm-keeper/api`, `@swarm-keeper/worker`, `@swarm-keeper/web`, `@swarm-keeper/permissions`, `@swarm-keeper/design-tokens`, `@swarm-keeper/api-client`, `@swarm-keeper/web-core`, `@swarm-keeper/web-ui`, `@swarm-keeper/feature-<name>` for gallery, documents, upload, family, people, search, trash, settings.
- Every dependency version is the latest stable (check with `pnpm view <pkg> version`) and pinned exactly, shared versions via the `catalog:` in `pnpm-workspace.yaml`. No `^` or `~`.
- `"packageManager": "pnpm@12.14.0"`, `"engines": { "node": ">=26" }`, `.nvmrc` = `26`.
- All API routes under the global prefix `api/v1`.
- Angular: standalone, zoneless (no `zone.js` dependency), no SSR, OnPush, templates contain no literal text, styles in SCSS.
- Out of scope: Docker Compose, Better Auth, DB, pg-boss, Transloco, Material, Style Dictionary, OpenAPI generation, PWA, CI.
- Commits only when the owner says so (repo has no commits yet). Commit steps below are prepared commands, executed on approval, using Conventional Commits.

## Review Focus

1. Running the **built** API/worker with plain `node` (not via Vitest) must resolve `@swarm-keeper/*` imports — Task 3/4 verify `node dist/...` starts.
2. The web app importing a library through its alias must build with the Angular builder — Task 5 imports `@swarm-keeper/web-core` from `app.config.ts`.
3. Worker receiving SIGTERM must close the Nest context and exit with code 0, not hang — Task 4 test.
4. Sheriff must actually fail on a cross-feature import and on a deep import into another API module — Task 6 negative checks.
5. The generated Angular template must not keep CLI placeholder text — Task 5 check that `app.html` contains only `<router-outlet />`.
