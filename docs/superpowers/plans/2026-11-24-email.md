# Email (step 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Invitation, email-verification and password-reset emails in `en` and `ru`, HTML plus `text/plain`, sent over SMTP and visible in a dev Mailpit.

**Architecture:** New API module `apps/api/src/modules/mail` (SMTP transport over nodemailer, mail settings, shared HTML layout, `escapeHtml`, a Mailpit reader for tests). In `identity`: texts in `mail/i18n/{en,ru}.json`, `auth-emails.ts` renders them, `SmtpMailer implements Mailer` replaces `LoggingMailer` in `MailerModule`; `create-auth.ts` passes locale, inviter, family and expiry.

**Tech Stack:** nodemailer 10.6.1 (+ `@types/nodemailer` 8.0.2), Mailpit `axllent/mailpit:v1.34.0`, Better Auth 1.7.27, NestJS 12, Vitest 5, supertest.

**Spec:** `docs/superpowers/specs/2026-11-24-email-design.md`

## Global Constraints

- Locales: `'en' | 'ru'`; anything else falls back to `en`.
- Env: `SMTP_URL` (dev default `smtp://127.0.0.1:1025`), `MAIL_FROM` (dev default `Swarm Keeper <noreply@swarm-keeper.test>`), `MAILPIT_URL` (tests only, default `http://127.0.0.1:8025`). Defaults apply only when `NODE_ENV` is `development` or `test`; otherwise missing `SMTP_URL`/`MAIL_FROM` throws, like `authEnv`.
- Mailpit ports: SMTP `127.0.0.1:1025`, UI/API `127.0.0.1:8025`.
- "Swarm Keeper" is never translated. Glossary: Family / Семья, Invitation / Приглашение. Russian uses formal «вы»; no exclamation marks; English in sentence case.
- Colors in the layout (light theme of `docs/design/tokens.json`): `surface-100` `#f7f4ef`, `surface-000` `#ffffff`, `ink` `#1f1b16`, `ink-muted` `#5c544a`, `brand` `#2f5d8c`, `on-brand` `#ffffff`, `border` `#d6cec2`. Spacing/radius from the same file (`space-4` 16px, `space-6` 24px, `radius-sm` 6px).
- Dates in emails: `Intl.DateTimeFormat(locale, { dateStyle: 'long' })`.
- nodemailer pinned exactly, in `apps/api` and `apps/worker` dependencies.
- ESM, `.js` suffixes, Sheriff boundaries (identity imports mail only via `modules/mail/index.ts`), Conventional Commits with the Claude co-author line.

## Review Focus

1. A family or inviter name with markup or `&` (`<b>Tom & "Jerry"</b>`) is escaped in HTML, but appears as typed in the subject and the text part — Task 3 test.
2. A name containing CR/LF must not break into email headers: the subject has no `\r` or `\n` — Task 3 test.
3. A link with a query string (`…/reset-password/tok?callbackURL=/x&y=1`) keeps working: `&amp;` in the HTML `href`, raw in the text part — Task 2 test.
4. Locales like `ru-RU`, `RU`, `null`, `de` resolve to `ru`, `ru`, `en`, `en` — Task 3 test.
5. Production start without `SMTP_URL` or `MAIL_FROM` fails instead of silently using Mailpit defaults; an SMTP failure propagates from `SmtpMailer` (not swallowed) — Task 2 and Task 4 tests.

### Task 3: Auth email texts and rendering

**Files:**
- Create: `apps/api/src/modules/identity/mail/i18n/en.json`, `ru.json`, `apps/api/src/modules/identity/auth-emails.ts`, `auth-emails.spec.ts`

**Interfaces:**
- Consumes: `renderLayout`, `OutgoingMail` from `../mail/index.js` (Task 2).
- `type EmailLocale = 'en' | 'ru'`; `emailLocale(value: unknown): EmailLocale` — lowercases, takes the part before `-`/`_`, `ru` → `ru`, else `en`.
- `invitationEmail(input: { to: string; url: string; locale: unknown; inviterName: string; familyName: string; expiresAt: Date }): OutgoingMail`; `verifyEmailEmail(input: { to; url; locale: unknown }): OutgoingMail`; `resetPasswordEmail(input: { to; url; locale: unknown }): OutgoingMail`.
- Placeholders `{inviter}`, `{family}`, `{date}` are replaced with plain `String.replaceAll` (no plurals here, so no ICU). Subject: placeholders filled, then `\r`/`\n` replaced by spaces. Text part: heading, paragraphs, label + `: ` + url, notes, footer, separated by blank lines.

JSON shape (both files, same keys): `{ "footer", "invitation": { "subject", "heading", "body", "action", "expires", "ignore" }, "verifyEmail": { "subject", "heading", "body", "action", "ignore" }, "resetPassword": { "subject", "heading", "body", "action", "expires", "ignore" } }`. Exact copy:

| key | en | ru |
| --- | --- | --- |
| footer | Swarm Keeper · family archive | Swarm Keeper · семейный архив |
| invitation.subject | Invitation to the family “{family}” | Приглашение в семью «{family}» |
| invitation.heading | Invitation to the family “{family}” | Приглашение в семью «{family}» |
| invitation.body | {inviter} invites you to the family “{family}” in Swarm Keeper, a shared archive of family photos and documents. | {inviter} приглашает вас в семью «{family}» в Swarm Keeper — общий архив семейных фотографий и документов. |

| verifyEmail.subject / heading | Confirm your email | Подтвердите email |
| verifyEmail.body | Confirm that this address is yours to keep using Swarm Keeper. | Подтвердите, что это ваш адрес, чтобы продолжить работу в Swarm Keeper. |
| verifyEmail.action | Confirm email | Подтвердить email |
